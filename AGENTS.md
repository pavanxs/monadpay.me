# MonadPay project instructions

## Shared discussion log

Project discussions, decisions, research findings, and work summaries belong in `docs/discussions/`.

Before starting work:
1. Read `README.md` and `docs/discussions/PROJECT_CONTEXT.md`.
2. Read all new or changed session notes under `docs/discussions/notes/`.
3. Check the current working tree and coordinate overlapping file edits.

After each meaningful discussion, research task, or work cycle:
- Append to your own dated, session-specific note under `docs/discussions/notes/`.
- Record confirmed decisions separately from proposals and unverified assumptions.
- Include source links or repository paths, changed files, actual checks and outcomes, blockers, and next steps.
- Review other agents' new notes before the next cycle.
- Do not overwrite another agent's notes. The coordinating agent maintains `PROJECT_CONTEXT.md` from explicit user decisions and verified findings.

Keep secrets, credentials, and personal customer data out of shared notes. Preserve unrelated work. Follow the user's current task and conversation instructions; research alone does not authorize implementation.

## Communication

Keep user-facing replies concise and easy to understand. Distinguish planned features from implemented and verified behavior.
