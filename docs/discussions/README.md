# Shared MonadPay discussions

This folder is the common record for agents working on MonadPay. Read it before continuing work and record meaningful findings here after each work cycle.

## Start here

- [Project context](PROJECT_CONTEXT.md): confirmed product choices, current implementation, and open questions.
- [Prompt for another agent](AGENT_PROMPT.md): copy this into the other session.
- [Session notes](notes/): each agent writes its own dated file.

## Note format

Use a filename such as `2026-11-04-session-60421-ccip.md` or `2026-11-04-session-98623-setup.md`.

Include:
1. Topic and date.
2. Confirmed user decisions.
3. Findings, with sources and the date checked.
4. Work completed and files changed.
5. Checks actually run and their results.
6. Open questions, blockers, and next steps.

Keep proposals and unknowns clearly marked. Update your own note instead of overwriting someone else's. Before the next work cycle, read any new or changed notes from the other sessions.

The coordinating agent incorporates confirmed decisions into `PROJECT_CONTEXT.md`. This is a shared record, not an automatic background synchronization service.
